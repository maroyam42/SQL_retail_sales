# 🛍️ Retail Sales Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing retail sales data using **SQL** to extract meaningful business insights and answer key business questions.

The project covers the complete SQL analysis workflow, including:

* Data cleaning
* Data exploration
* Data aggregation
* Customer analysis
* Category analysis
* Sales performance analysis
* Time-based analysis
* Business insights

The goal is to practice SQL concepts on a real-world-style retail dataset and transform raw sales data into useful insights for decision-making.

---

## 🗂️ Dataset

The dataset contains retail transaction information with the following columns:

| Column            | Description                    |
| ----------------- | ------------------------------ |
| `transactions_id` | Unique ID for each transaction |
| `sale_date`       | Date of the sale               |
| `sale_time`       | Time of the sale               |
| `customer_id`     | Unique customer ID             |
| `gender`          | Customer gender                |
| `age`             | Customer age                   |
| `category`        | Product category               |
| `quantity`        | Number of items purchased      |
| `price_per_unit`  | Price per unit                 |
| `cogs`            | Cost of goods sold             |
| `total_sale`      | Total value of the transaction |

## 🧹 Data Cleaning

Before starting the analysis, I checked the dataset for missing values in important columns.

### Missing Values Check

```sql
SELECT COUNT(*)
FROM retail_sales
WHERE transactions_id IS NULL
   OR sale_date IS NULL
   OR customer_id IS NULL
   OR gender IS NULL
   OR category IS NULL
   OR quantity IS NULL
   OR price_per_unit IS NULL
   OR cogs IS NULL
   OR total_sale IS NULL;
```

Rows containing missing values were removed to ensure the analysis was performed on complete records.

## 📊 Business Questions & SQL Analysis

The project answers several business questions using SQL.

### 1. Sales on a Specific Date

Retrieve transactions made on a specific date.

### 2. Clothing Sales Analysis

Find Clothing transactions where the quantity sold is greater than 10 during November 2022.

### 3. Total Sales by Category

Calculate the total sales generated by each product category using:

* `SUM()`
* `GROUP BY`

### 4. Average Customer Age in Beauty

Calculate the average age of customers who purchased products from the Beauty category.

### 5. High-Value Transactions

Identify transactions where total sales exceeded 1000.

### 6. Transactions by Gender and Category

Analyze the number of transactions for each gender within each product category.

### 7. Best-Selling Month per Year

Analyze monthly average sales and identify the month with the highest average sale in each year.

This analysis uses:

* `EXTRACT()`
* `AVG()`
* `GROUP BY`
* `RANK()`
* `PARTITION BY`

### 8. Top 5 Customers

Identify the top 5 customers based on their total sales.

### 9. Unique Customers by Category

Calculate the number of unique customers purchasing from each category.

### 10. Sales by Time Shift

Divide transactions into three shifts:

| Shift     | Time         |
| --------- | ------------ |
| Morning   | Before 12 PM |
| Afternoon | 12 PM – 5 PM |
| Evening   | After 5 PM   |

This was implemented using a `CASE` statement.
